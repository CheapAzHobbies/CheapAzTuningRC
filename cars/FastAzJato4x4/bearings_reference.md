# Bearings Reference — FastAzJato4x4

Not a tuning decision — just the full list of bearings the build needs. Sizes/quantities match the **Traxxas Jato 4x4 BL-2s (90154-4) complete bearing kit** — it's a 1/8-class platform, so bigger bearings than a Slash 4x4. Run sealed (rubber-shielded) bearings throughout for offroad.

| Size (mm) | Qty | Typical location |
|---|---|---|
| **6×12×4** | 6 | Wheel hubs / axle carriers |
| **12×18×4** | 5 | Diffs + transmission / center driveline |
| **10×15×4** | 4 | Hubs / diff outdrives |
| **8×16×5** | 2 | Diff inputs |
| **5×8×2.5** | 4 | Steering bellcrank |
| **5×11×4** | 1 | Center / slipper |

**Total: 22 bearings.**

---

**Verify on this build:** the quantities above are the Jato 4x4 BL-2s kit baseline, and the "typical location" column is best-effort — Avid doesn't publish the exact per-position split. This is also a hybrid: it runs **E-Revo 1.0 diffs** and **Jato 4x4 / MonsterKingz alum front knuckles + carriers**, so the **diff** and **front-hub** bearings follow those parts. Pop them apart and confirm sizes against the actual hardware before ordering.
