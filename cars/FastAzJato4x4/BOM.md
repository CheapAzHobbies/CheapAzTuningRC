## Notes

- **ESC/motor combo:** **HobbyWing MAX10 G2 140A + EZRun 3665SD G3 2400KV** (bought Jun 25 2026, $127), a matched pair, so the G3 sensor plug needs no adapter. Supersedes the Fire Phoenix + Tekin Pro4 HD plan; both drop to spares. See [`esc_analysis.md`](esc_analysis.md) / [`motor_analysis.md`](motor_analysis.md).
- **Arms:** running **FLM26800 metal arms front + rear** (ProTrac PRO6082-01 dropped). Both pairs are from the FLM bulk buy (already sunk). See [`arm_analysis.md`](arm_analysis.md).
- **Springs, pistons, oil:** the white 59gf front + grey 52gf rear springs **and** the 1.4mm×6 pistons **came with the used D8 shock set** ($0 extra). Shock oil bought separately from **Tammies**.
- **Output shafts:** bought 4× TRA6752 long shafts, but only the **front** needs them; the **rear keeps stock-length**, so **only 2 are used** and 2 are spare. 🚧 update [`driveshaft_analysis.md`](driveshaft_analysis.md#2wd-long-cvds--6752-output-shafts-cheap-long-axle-build) to spec 2-front.
- **Cooling fan / heatsink:** not in the BOM. The combo motor is IP67 and 4S-native; the old Tekin-based cooling analysis no longer applies. See [motor_analysis.md](motor_analysis.md#related-motor-cooling-optional).
- **Shock tower brace (TRA9061):** [vetoed](shock_tower_analysis.md#related-tower-bracing-optional), not in the BOM.
- **6mm vs 5mm drivetrain:** **5mm**, the stock Jato 4x4 diffs mate the Slash 4x4-pattern CVDs (knock-off, in hand) on Tekno M6 stubs. The E-Revo diffs/CVDs/drive cups (6mm) are spares. See [differential_analysis.md](differential_analysis.md).
- **Aluminum gearbox housings:** vetoed, the CF chassis already has a metal skid plate protecting the diffs from below. See [gearbox_housing_analysis.md](gearbox_housing_analysis.md#why-aluminum-isnt-worth-it-on-this-build).
- **Aluminum bumpers / shock towers:** vetoed per the sacrificial-failure logic. Aluminum here is the bell crank only.
- **Meelobee technique:** OEM Jato **TRA9046** wing mount on a **Slash 4x4 Extreme HD rear tower (TRA9039)** with a small aluminum top plate. Shocks centered and protected, no STRC kit. See [`aero_analysis.md`](aero_analysis.md#shock-tower-compatibility-cascade).
- **Spur:** **TRA3956R 54T** plastic, in hand ([`differential_analysis.md`](differential_analysis.md#spur-gear)). **Pinion:** TBD, [reference table](motor_analysis.md#pinion-reference-32p-tbd).
- **Shock bodies:** running the metal **Hot Bodies D8** (used set of 4, in hand); the plastic Apache C1 is the identical-internals backup. See [shock_analysis.md](shock_analysis.md#plastic-vs-metal-body-trade-off).

For everything else (primary body, wheels/tires, pinion, bearing kit) still being researched, see the [main README parts list](README.md#parts-list).
