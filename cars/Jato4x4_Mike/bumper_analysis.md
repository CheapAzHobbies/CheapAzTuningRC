# Bumper Selection — Jato4x4_Mike

> **Running: the Rustler 4x4 front bumper.** This is a real divergence from the [FastAzJato4x4](../FastAzJato4x4/bumper_analysis.md), which runs the **RPM 81042 wide front** instead.
>
> **Worth knowing:** the FastAz doc weighed this exact part and passed on it, not on protection but on looks. Its words: the Rustler front **"crushes on protection but loses on looks"**, and it **does not extend past the wheels**, so it stays recovery friendly. Mike took the protection.
>
> **The rear is not a divergence.** Both cars run the same **TRA9044** skid, the only rear plate that covers the tongue. Only the front differs.
>
> **Full comparison:** [FastAzJato4x4 bumper analysis](../FastAzJato4x4/bumper_analysis.md#bumper-options).

| Item | Spec |
|---|---|
| **Front bumper** | **Traxxas TRA6736**, Rustler 4x4 front bumper **+ support**, glass-filled nylon |
| **Rear skid** | **Traxxas TRA9044**, same as the FastAz. Sold as a front + rear set, **only the rear is used**, and it is the only rear plate that covers the tongue |
| **Rear bumper** | 🚧 not recorded. The matching Rustler rear is **TRA6737** |
| **Price** | **$6.00** bumper, **$7.00** the skid set |

⚠️ **Do not order the LED versions by mistake.** TRA6797 and TRA6736X are the LED variants, and the FastAz doc rules LEDs out of a front bumper entirely: the front takes direct hits and lights in the impact zone get destroyed.
