## Buy Decision

See [included_parts_analysis.md](included_parts_analysis.md) for the full math. Short version:

- **Car + electronics only (if it runs):** ~$420–500. Target **$375–425**.
- **With spares that fit (if car = MBX7TR-E):** package value **$650–900**.
- **With spares that *don't* fit (if car = MBX8):** spares become resale-only; package ~$425–500 + a box of flippable Mugen parts.

**Verdict:** good-to-great deal **if** (a) the chassis is confirmed as the 7-series truggy the spares fit, (b) it runs, and (c) you actually want to run/maintain a high-end 1/8 truggy. If you just want a basher, you'd be paying for a parts library you won't use.
